# Zero EMU

A dual-screen handheld emulator for iPhone, designed for the foldable iPhone Duo. It runs on other iPhones too.

为双屏折叠 iPhone 设计的掌机模拟器，普通 iPhone 也能用。

- Support / 支持: https://zero-emu.github.io/zero-emu/support.html
- Privacy policy / 隐私政策: https://zero-emu.github.io/zero-emu/privacy.html
- Contact / 联系: zeroemu@outlook.com

This repository holds Zero EMU's support and privacy pages. The source code of each released version of the app (GNU General Public License v3.0) is published here when that version is released.

这个仓库放的是 Zero EMU 的支持页和隐私政策页。App 每个发布版本的源码（GNU 通用公共许可证第 3 版）在该版本发布时放在这里。

Zero EMU ships with no games, keys, firmware or system files, and offers no downloads of or links to any. Zero EMU is not affiliated with, authorized or endorsed by any console maker.

Zero EMU 不附带任何游戏、密钥、固件或系统文件，也不提供它们的下载或链接。Zero EMU 与任何游戏主机厂商没有关联。
