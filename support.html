常见问题

怎么把软件放进 Zero EMU？

在游戏库里，点掌机主菜单上的「导入」，从「文件」里选；或者在「文件」里通过共享菜单用 Zero EMU 打开。支持已解密的 .cci、.cxi、.app 文件和自制软件的 .3dsx、.elf。加密的文件会被拒绝，并说明原因。Zero EMU 不附带、也不提供任何游戏、密钥、固件或系统文件。

存档在哪里？

软件自己的存档在模拟机的存储里：「文件」App › 我的 iPhone › Zero EMU › Azahar，可以备份或拷到电脑。HOME 菜单里的「保存进度」是即时存档，在 App 内部。系统设置 › 数据管理 › 备份 可以把存档导出成一个文件；存档同步可以把存档放到你自己的 iCloud。

有的游戏只能点屏幕，按键没反应？

游戏里按 HOME，打开顶上那排小图标里的「按键点屏」。之后 A、B、X、Y 按下去就等于点一下触摸屏，点在你上一次用手指点过的位置。这个开关每个游戏单独记。

能用手柄吗？

能。支持系统认得的扩展手柄（例如 MFi、Xbox、PlayStation 手柄）。按键按位置对应：右 A、下 B、上 X、左 Y；L / R 肩键，ZL / ZR 扳机；左摇杆是 Circle Pad，右摇杆是 C Stick；Menu 是 START，Options 是 SELECT。手柄的 Home 键（系统不占用它时）打开 HOME 菜单，再按继续。

合上盖子会怎样？

在 iPhone Duo 上，合盖时软件暂停，外屏显示机身外壳；打开盖子就接着玩。合盖前已经暂停的，打开后仍是暂停。

为什么有的软件很慢，或者打不开？

iOS 不允许 App 即时编译代码，Zero EMU 的模拟处理器只能逐条解释执行，所以画面复杂的 3D 软件可能达不到全速。需要主机系统文件的软件无法运行，Zero EMU 会弹出说明。软件运行中出错时，Zero EMU 会提示"软件出错，已停止运行"，关闭后可以重新打开。

Questions

How do I add software?

In the library, tap Import on the console's menu and pick a file in Files, or open a file in Zero EMU from the share menu in Files. Decrypted .cci, .cxi and .app files and homebrew .3dsx / .elf are supported; encrypted files are rejected, and Zero EMU says why. Zero EMU does not include or provide any games, keys, firmware or system files.

Where are my saves?

Software saves live in the emulated system's storage: Files › On My iPhone › Zero EMU › Azahar — back it up or copy it to a computer. Save states made from the HOME menu stay inside the app. System Settings › Data Management › Backup exports the saves as one file; save sync can keep them in your own iCloud.

A game only reacts to the touch screen — the buttons do nothing?

Press HOME in the game and turn on Key taps in the row of small icons at the top. A, B, X and Y then tap the touch screen for you, at the place your finger touched last. The switch is kept per game.

Can I use a controller?

Yes, any extended gamepad the system recognizes (MFi, Xbox, PlayStation…). Buttons are mapped by position: right A, bottom B, top X, left Y; L / R shoulders, ZL / ZR triggers; left stick = Circle Pad, right stick = C Stick; Menu = START, Options = SELECT. The controller's Home button (when the system does not use it) opens the HOME menu; press it again to continue.

What happens when I close the lid?

On iPhone Duo the software pauses while the lid is closed and the cover shows the shell; open the lid and play on. Software you paused before closing stays paused.

Why is some software slow, or won't start?

iOS does not let apps compile code at run time, so Zero EMU's emulated processor is an interpreter; demanding 3D software may not reach full speed. Software that needs the console's system files cannot run, and Zero EMU says so. When running software fails, Zero EMU tells you it has stopped; close it and open it again.
